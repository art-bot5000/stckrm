Household Consumables Tracker. Stock estimates are calculated from your purchase history, quantity per purchase, and months-of-supply settings. Data syncs securely to the cloud, encrypted on your device. Export regularly as an additional backup.

Secure notes found

Your export contains secure notes. How would you like to handle them?

Heads-up: if you include them, the bodies are written as plain text in the file (so the backup is human-readable). They’re tagged for automatic re-encryption when the file is imported back into a STOCKROOM account — secure notes will become secure again on the destination device.

Backup downloaded — plaintext warning

Your backup file contains 0 secure note as plaintext. Treat the file as sensitive — anyone who opens it can read the content.

The notes are tagged so that when you (or anyone you trust) import this file back into the app, those bodies are automatically re-encrypted with the destination account's key and the locked state is restored. You don't need to re-lock them manually after import.

Deactivate your account?

Your account will be disabled for up to 3 months. During this time:

  • You will not be able to sign in
  • Your data is preserved on our servers
  • You'll receive a reminder email 1 week before the 3 months is up
  • If no action is taken, a final warning period begins before the account is marked for deletion
Tip: Export your data in the Data section before deactivating.
